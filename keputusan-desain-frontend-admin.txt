1. GAYA VISUAL YANG DIPILIH
----------------------------------------------------------------
- Referensi gaya: mirip template "Spike Admin" (Wrappixel) — HANYA
  diambil gaya visualnya, dibangun ulang sendiri dari nol dengan
  Tailwind CSS (bukan pakai source code/asset asli template
  tersebut, karena itu produk komersial).
- Ciri visual yang diadopsi:
    - Card dengan soft shadow (bukan flat/border tipis):
      box-shadow: 0 2px 10px rgba(20,20,50,0.06)
    - Border radius lebih besar (~14-16px), kesan lebih lembut
    - Icon badge bulat/rounded-square berwarna pastel (background
      lembut + ikon warna solid), dipakai konsisten di semua kartu
      statistik
    - Warna dipakai secara semantik: hijau = baik/selesai,
      kuning = perlu perhatian, merah = masalah/belum dibayar
    - Font: Inter atau Plus Jakarta Sans (bukan default Tailwind)
    - Icon set: Tabler Icons (outline style)
    - Grafik terintegrasi langsung di dalam card dashboard
      (bukan halaman terpisah) — rencana pakai ApexCharts

tiap role cuma lihat menu yang relevan (Guru vs Bendahara vs Admin).

migration/model. Modul Akademik/Learning/Exam/dll BELUM dibangun
skema database-nya — sidebar di atas adalah peta jangka panjang,
JANGAN dibuatkan menu/link fisik untuk modul yang belum ada
halamannya (hindari dead link).

3. STRUKTUR DIREKTORI VIEWS (BLADE)
----------------------------------------------------------------
resources/views/
├── layouts/
│   └── admin.blade.php          <- shared, DI LUAR folder modules/
├── components/                  <- shared, DI LUAR folder modules/
│   ├── icon-badge.blade.php
│   ├── status-badge.blade.php
│   ├── admin-sidebar.blade.php
│   └── admin-navbar.blade.php
└── modules/
    ├── auth/
    │   ├── login.blade.php
    │   └── dashboard.blade.php
    └── finance/
        ├── dashboard.blade.php
        ├── invoices/
        │   ├── index.blade.php
        │   └── show.blade.php
        └── payments/
            └── index.blade.php

KEPUTUSAN: layout dan component reusable TIDAK ikut ditaruh di
dalam folder modul — karena dipakai lintas banyak modul sekaligus
(sama alasannya dengan kenapa model User ditaruh di App\Models,
bukan di dalam module Auth). Kalau dipaksa taruh di dalam satu
modul, modul lain jadi "meminjam" komponen dari modul yang tidak
berkaitan — melanggar prinsip zero cross-module dependency yang
sudah diterapkan di backend.

Pemanggilan view TETAP pakai dot notation standar Laravel:
  view('modules.auth.login')
  view('modules.finance.invoices.index')

KEPUTUSAN: TIDAK memakai custom view namespace (mis. view('auth::login')
via loadViewsFrom). Cukup pakai konvensi standar Laravel — dot
notation langsung merepresentasikan path folder, tidak perlu
lapisan alias tambahan.

4. STRUKTUR DIREKTORI CSS
----------------------------------------------------------------
resources/css/
└── app.css                      <- SATU-SATUNYA entry Tailwind global

KEPUTUSAN: TIDAK membuat file CSS terpisah per halaman/modul.
Karena Tailwind adalah utility-first (styling ditulis langsung
sebagai class di Blade, bukan CSS terpisah), file CSS per halaman
umumnya jadi mubazir (kosong/nyaris kosong) dan cuma menambah entry
Vite tanpa manfaat. File CSS tambahan HANYA dibuat kalau memang ada
override yang benar-benar tidak bisa direpresentasikan lewat utility
class (jarang terjadi).

----------------------------------------------------------------
5. STRUKTUR DIREKTORI JS
----------------------------------------------------------------
resources/js/
├── app.js                       <- global: init Alpine, toggle sidebar, dll.
└── modules/
    ├── auth/
    │   └── login.js             <- opsional, kalau ada logic khusus
    └── finance/
        ├── dashboard.js         <- init chart ApexCharts
        └── invoices/
            └── index.js         <- filter/search interaktif

KEPUTUSAN: JS DIPISAH per halaman, mengikuti path yang SEJAJAR
1:1 dengan struktur folder views/modules/. Ini memudahkan
menemukan pasangan file (Blade <-> JS) tanpa menebak-nebak dari
nama file, karena posisi foldernya identik.

File JS baru di resources/js/modules/** OTOMATIS terdaftar sebagai
entry Vite lewat glob pattern (lihat bagian setup di bawah) — tidak
perlu edit vite.config.js manual tiap kali bikin halaman baru.

6. LANGKAH SETUP YANG PERLU DILAKUKAN
----------------------------------------------------------------

a) Install dependency glob untuk auto-discover entry JS per modul:

    npm install glob --save-dev

b) Update vite.config.js:

    import { defineConfig } from 'vite';
    import laravel from 'laravel-vite-plugin';
    import { globSync } from 'glob';

    const moduleScripts = globSync('resources/js/modules/**/*.js');

    export default defineConfig({
        plugins: [
            laravel({
                input: [
                    'resources/css/app.css',
                    'resources/js/app.js',
                    ...moduleScripts,
                ],
                refresh: true,
            }),
        ],
    });

c) Layout utama load CSS + JS global, plus stack untuk script
   per halaman:

    {{-- resources/views/layouts/admin.blade.php --}}
    <!DOCTYPE html>
    <html lang="id">
    <head>
        @vite(['resources/css/app.css', 'resources/js/app.js'])
    </head>
    <body>
        <div class="flex min-h-screen">
            <x-admin-sidebar />
            <div class="flex-1 flex flex-col">
                <x-admin-navbar />
                <main class="p-6">{{ $slot }}</main>
            </div>
        </div>
        @stack('scripts')
    </body>
    </html>

d) Tiap halaman yang butuh JS spesifik, push lewat @vite di dalam
   @push('scripts'):

    {{-- resources/views/modules/finance/dashboard.blade.php --}}
    @extends('layouts.admin')

    @push('scripts')
        @vite(['resources/js/modules/finance/dashboard.js'])
    @endpush

e) Install ApexCharts untuk grafik dashboard (rencana):

    npm install apexcharts

f) Component reusable ditulis sekali, dipakai lintas modul:

    {{-- resources/views/components/icon-badge.blade.php --}}
    @props(['icon', 'color' => 'blue'])

    @php
    $colors = [
        'blue' => 'bg-blue-50 text-blue-600',
        'green' => 'bg-green-50 text-green-600',
        'amber' => 'bg-amber-50 text-amber-600',
        'red' => 'bg-red-50 text-red-600',
    ];
    @endphp

    <div class="w-9 h-9 rounded-[10px] {{ $colors[$color] }} flex items-center justify-center">
        <i class="ti ti-{{ $icon }} text-[17px]"></i>
    </div>

7. RINGKASAN KEPUTUSAN (CEPAT DIBACA)
----------------------------------------------------------------
| Aspek           | Keputusan                                    |
|-----------------|-----------------------------------------------|
| Views per modul  | YA — resources/views/modules/{modul}/...      |
| View namespace   | TIDAK — pakai dot notation standar             |

|                  | mirror folder dengan views/modules/            |

| Chart library    | ApexCharts (rencana)                           |
| Icon set         | Tabler Icons                                   |
| Font             | Inter / Plus Jakarta Sans                      |
